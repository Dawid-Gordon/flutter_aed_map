# Contributing to AED Map

## AI Development Rules (Gemini)

To ensure a clean and manageable codebase, all changes made by Gemini must follow these rules:

1.  **Branching Strategy**: All changes must be prepared on a new branch created from `main`.
2.  **Pull Requests**: Once changes are complete, a pull request (PR) must be created with a merge request to the `main` branch.
3.  **No Direct Pushes**: Do not push changes directly to the `main` branch.
